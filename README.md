# Huawei HG8245H — удалённая перезагрузка

Скрипт перезагружает роутер Huawei HG8245H через его веб-интерфейс и **автоматически определяет поколение прошивки**:

- **Современная прошивка** (`/api/` XML-интерфейс): токен `SesTokenInfo` → логин `user_login` → перезагрузка через `/api/system/reboot`.
- **Легаси-прошивка** (классический CGI-интерфейс, отвечает HTML на `/api/`): токен `GetRandCount.asp` → логин `login.cgi` (пароль в Base64, поля `UserName`/`PassWord`) → токен `hwonttoken` со страницы `reset.asp` → команда `ResetBoard` через `set.cgi`.

Проверено на прошивке МГТС (`CfgMode=MGTS`, HG8245H). Особенности этой прошивки, учтённые в скрипте:
- страница логина полностью управляется JS, форма без `action` — скрипт разбирает её и логирует подключаемые JS-файлы (`safelogin.js` и т.п.);
- для логина нужна кука с именем `Cookie` (заголовок `Cookie: Cookie=body:Language:english:id=-1`);
- сессия после логина выдаётся тоже кукой с именем `Cookie` (`Cookie=sid=<hash>:...`);
- **веб-сервер ONT (GoAhead) зависает, если POST приходит несколькими TCP-сегментами** — `requests` шлёт заголовки и тело раздельно, поэтому команда перезагрузки отправляется сырым сокетом одним `sendall()`;
- ответ `set.cgi` ничего не гарантирует: скрипт проверяет успех по факту — web-интерфейс должен перестать отвечать (иначе сообщается об ошибке). Перезагрузка проверена независимо по пингу наружу (провал ~60 с).

## Зависимости

```bash
pip install requests
```

## Использование

Впишите реквизиты в файл `.env` рядом со скриптом (шаблон — `.env.example`):

```
HG8245H_HOST=192.168.100.1
HG8245H_USER=root
HG8245H_PASSWORD=ВАШ_ПАРОЛЬ
```

И просто запустите:

```bash
./reboot_hg8245h.py
```

При желании можно переопределить параметры флагами или переменными окружения (приоритет: флаги CLI > переменные окружения > `.env`):

```bash
./reboot_hg8245h.py --host 192.168.100.1 --user root --password 'ВАШ_ПАРОЛЬ'
```

Адрес по умолчанию — `192.168.100.1`, пользователь `root` (у некоторых провайдеров — `telecomadmin`).

Пример задания в cron (перезагрузка каждый день в 5:00):

```
0 5 * * * cd /home/exo/Projects/huawei_HG8245H_remote && ./reboot_hg8245h.py
```

## Отладка

- Каждый запуск пишет подробный лог в `reboot.log` рядом со скриптом: все HTTP-запросы, коды ответов, тела и заголовки (пароль маскируется `***`).
- `./reboot_hg8245h.py -v` — тот же подробный вывод ещё и в консоль.
- `--no-log-file` — не писать лог-файл; `--log-file ПУТЬ` — писать в другое место.
- В консоли видно, какой режим выбран (API или legacy) и какой endpoint принял команду. Если перезагрузка не происходит, пришлите `reboot.log` — по телам ответов видно, что отвечает прошивка.

## Примечания

- Скрипт поддерживает два варианта хеширования пароля (новые прошивки хешируют пароль с токеном, старые шлют base64) — пробует оба автоматически.
- Прошивки у HG8245H от разных провайдеров отличаются; если логин не проходит, проверьте учётные данные (часто admin-доступ заблокирован провайдером) и пришлите мне код ответа роутера — скорректирую endpoint.
